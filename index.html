System Toolbox

by mraz0tix (11 y.o. Python Developer)

О проекте

Мощная консольная утилита на Python для администрирования. Автоматизирует проверку сети, сканирует активные сокеты и собирает полную сводку о системе, экономя ваше время.

Возможности Toolbox

Код проекта: 82 строки

Сеть (Ping)

Быстрая проверка интернет-соединения с серверами Google с помощью отправки ICMP-пакетов через модуль subprocess.

Инфо (Uname)

Вывод подробных данных о ядре операционной системы компьютера в один клик.

Порты (ss)

Мониторинг активных и слушающих сетевых портов системы в реальном времени с ключами -tuln.

Сводка (Fastfetch)

Красивый вывод логотипа ОС и системных характеристик железа с обработкой ошибок установки.
